# How to install

1. Clone repository
```bash
git clone https://github.com/Mount-IDE/Mount.git
```
2. Install dependencies
```bash
npm i
```
3. Compile project
```bash
# dev 
npm run tauri
# release
npm run tauri:release
```

4. Run
```bash
./mount
```
